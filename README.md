# Hospital Management System

A dynamic console utility built using *C++* to map healthcare operations and handle patient data workflows.

## 💡 Overview
This project simulates real-world healthcare management by tracking patient data entries, system queries, and symptom logging. I designed and coded this application during my *3rd Semester of Associate Degree Program (ADP) in Computer Science* to practice object-oriented programming concepts.

## 🚀 Key Modules
- *Patient Registration:* Securely capture essential patient information such as ID, Name, Age, and current symptoms.
- *Active Database Query:* Instantly lookup critical patient records using unique numeric IDs.
- *Memory Optimization:* Implemented dynamic arrays through C++ STL Vectors for stable resource management.

## 🛠️ Technical Concepts Applied
- Object-Oriented Design (Classes, Objects, and Methods)
- Encapsulation (Private fields with Public Accessors)
- Dynamic Data Structures via C++ STL
